# 参考来源与致谢

## 这本书是什么

一份讲通用概念的大模型入门手册。**不绑定任何一家模型或工具**——书里的方法在 GPT、Claude、Gemini、DeepSeek、豆包、通义、Kimi 上都成立。

写它的出发点很简单：市面上要么是"10 个提示词技巧"这种没有骨架的清单，要么是从 Transformer 讲起的技术文档。中间那一层——**你得先知道它是个什么东西，那些技巧才不用背**——反而没人好好讲。

## 关于准确性

三条自我约束：

**不写会过期的东西。** 具体的版本号、价格、上下文窗口的确切数字、模型排行榜——一律不写死，只给量级和判断维度。要精确数字请查官方页面。

**例外是[模型篇](../models/)和[工具篇](../tools/)**——"市面上有哪些模型 / 有哪些工具"这两个问题绕不过去。这两篇的处理办法一样：只写是谁、叫什么、结构上以什么见长 / 给谁用，每条配官方入口让你自己核；不写版本号、跑分、价格和排名。内容截至 2026 年 9 月，与官网不一致时以官网为准。

**不排名。** 哪家模型更强这个月和下个月答案就不一样，而且跟你的任务类型强相关。书里只给你"怎么自己测"的方法。

**区分事实和判断。** 机制层面的东西（它怎么工作、为什么会编）是确定的；"该怎么用"是建议，你完全可以有不同做法。

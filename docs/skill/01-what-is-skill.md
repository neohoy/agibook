# 01 · Skill 是什么

<div class="ab-def">

**Skill**（技能）是一个**可复用的能力包**：把某类活的规矩、流程、模板、示例打包成一份说明书，存起来。以后遇到这类活，一句话触发，它自动照着做——不用你每次重讲。

</div>

## 用带新人的说法

新人来了三个月，你发现自己在重复同一段话：

> "我们的会议纪要要分三块，待办必须带责任人和截止时间，人名一律用原文的称呼不要补全，拿不准的写待确认……"

老员工不用你说这些，因为公司有 **SOP 手册**。新人看一遍手册，以后就照着做了。

**Skill 就是给 AI 的那本 SOP。** 区别只有一个：真人看一遍就记住了，AI 每次都要重新翻——但翻书这个动作是自动的，你不用管。

## 它跟 Prompt 到底差在哪

三个实质区别，不是文字游戏：

### 一、存在哪里

Prompt 存在你的聊天记录里、你的备忘录里、你的脑子里。Skill 存在**一个文件（夹）里**——可以提交到仓库、可以发给同事、可以有版本号、可以被 review。

**这一条决定了它能不能成为团队资产。**

### 二、什么时候进入上下文

Prompt 是你贴进去的，贴了就占地方。

Skill 是**按需加载**的：平时只有它的"名字 + 一句话说明"待在那儿（很小），只有当你说的话跟它对上号了，完整内容才被读进来。

这就是为什么你可以同时装二十个 Skill 而不担心把[上下文](../start/04-context)撑爆——**没被触发的那十九个，几乎不花钱**。

### 三、谁负责决定用不用它

Prompt：你决定。你贴了就用，不贴就不用。

Skill：**AI 自己判断**。你说"帮我把这段记录理一下"，它扫一眼手上有哪些 Skill，发现有个叫"整理会议纪要"的、说明里写着"用于把零散会议记录整理成结构化纪要"，就自己把它翻出来照着做。

::: warning 第三条是最大的认知转折
这意味着**你写 Skill 的时候，有一半功夫要花在"让它认得出该用这个"上**，而不只是"用了以后该怎么做"。

很多人的第一个 Skill 内容写得很好，但从来没被触发过——问题出在那句说明上。[04 章](./04-description)专门讲这个。
:::

## 它不是什么

**不是一个软件，也不是一个插件。** 它就是一份带格式的说明书，主体是 Markdown 文本。

**不是新的模型能力。** Skill 不会让模型变聪明，只是把你的规矩稳定地喂给它。**模型不会的事，Skill 也变不出来。**

**不是知识库。** 塞一百页产品文档进 Skill，不如做 [RAG](../start/09-map)。Skill 装的是**怎么做事的规矩**，不是**要查的资料**（虽然可以带少量参考文件，见 [03 章](./03-anatomy)）。

**不是 Agent。** Agent 是"给个目标自己跑完全程"的工作模式；Skill 是它跑的时候可以翻的手册。两者常一起出现，但不是一回事。

## 一个最小的 Skill 长什么样

不同平台的具体形式有差别（[09 章](./09-platforms)有对照表），但形状是一样的：**一句触发说明 + 一段做事的规矩**。

以目前最标准化的那种形式（一个文件夹，里面放一个 `SKILL.md`）为例：

```markdown
---
name: meeting-notes
description: 把零散的会议记录整理成结构化纪要，输出结论、带责任人的待办、
  遗留问题三块。当用户提供会议记录、会议录音转写稿，或要求整理纪要、
  提取会议待办时使用。
---

# 会议纪要整理

## 输出结构

一、关键结论 / 已定事项
二、待办事项（表格：事项 | 负责人 | 截止时间）
三、遗留 / 待确认问题

## 规则

- 只用用户给的材料，不引入外部信息
- 人名沿用原文称呼，不要补全
- 负责人或时间不明确的，写「待确认」，不要猜
- 材料里前后矛盾的，两个都列出来并标「原文冲突」
```

上半截（`---` 之间）是**给系统看的**：它靠这个决定要不要用你。下半截是**给模型看的**：真要用了，才读这一段。

看着眼熟吗？——**这就是你在[提示词篇](../prompt/10-checklist)调好的那条提示词，去掉"这一次的材料"，换个地方存。**

## 所以真正的流程是

```text
1. 用 Prompt 把一件事做对          ← 提示词篇
2. 同样的事做第三遍，开始烦了       ← 信号
3. 把那条提示词里"每次都一样"的部分抽出来
4. 加一句"什么时候该用我"
5. 存成 Skill
6. 以后一句话触发
```

第 3 步是重点：**Skill 里只留每次都一样的东西**。"这次的会议记录"是变的，不进 Skill；"纪要要分三块"是不变的，进。

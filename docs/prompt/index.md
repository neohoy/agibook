# 提示词篇 · 从"能用"到"每次都能用"

[入门篇](../start/06-prompt) 教了五要素，那是骨架。骨架撑起来之后，你很快会撞上第二堵墙：

> **同一条提示词，昨天跑出来很好，今天跑出来一般；给同事用，他跑出来的又是另一回事。**

能写出一条"这次挺好"的提示词，和能写出一条"谁跑、跑几次都稳定"的提示词，是两件事。这一篇讲的是后者。

## 这一篇和入门篇的区别

| | 入门篇 06 章 | 提示词篇 |
| --- | --- | --- |
| 目标 | 让这一次的结果能用 | 让每一次的结果都能用 |
| 尺度 | 一条提示词 | 一条提示词的生命周期：写、测、改、交接 |
| 判断标准 | "这次挺好" | 可复现、可验收、别人拿去也能跑 |
| 适合 | 刚开始用 | 已经用了一阵，开始被结果不稳定折磨 |

::: tip 没读过入门篇也能进
但至少先扫一眼 [06 · Prompt 五要素](../start/06-prompt)。这一篇默认你已经知道"角色 / 任务 / 背景 / 要求 / 验收"是什么。
:::

## 一句话先给你

这一篇所有内容可以压缩成一句：

> **提示词不是写给 AI 的作文，是写给一个新人的作业说明书——说明书的好坏，看的是"另一个人照着做能不能做对"。**

你写完一条提示词，问自己一句"把这段话给同事，他能不能照着交出我想要的东西"。答不上来，就是还没写完。

# 入门篇 · 一小时把大模型搞明白

这一篇要解决的不是"你会不会用 AI"，而是"你知不知道它是个什么东西"。

大部分人用不好大模型，不是因为提示词技巧不够花哨，是因为对它有个错误的想象——以为它是个会查资料的搜索引擎，或者是个记得住你的助理。它两个都不是。等你知道它到底怎么工作，那些所谓的技巧就不用背了，你自己能推出来。

## 这一篇怎么安排的

十篇正文，四段：

| 段 | 篇目 | 你会拿到什么 |
| --- | --- | --- |
| **它是什么** | 01–02 | 一个不会骗你的心智模型：预测下一个字的引擎 / 刚入职的天才新人 |
| **它的边界** | 03–05 | Token、上下文窗口、幻觉——它为什么会忘、会编，什么时候会 |
| **怎么使唤它** | 06–08 | Prompt 五要素、System Prompt，加一个从头做到尾的真实任务 |
| **接下来去哪** | 09–10 | Prompt / Skill / Agent / MCP 的全景地图，怎么挑模型和工具 |

按顺序读，一小时左右。中间的实操（[08](./08-first-task)）建议边读边跟着做一遍——只看不动手，这一篇的价值会掉一半。

## 三个前提说明

**不绑定任何一家。** 全书的例子在 GPT、Claude、Gemini、DeepSeek、豆包、通义、Kimi 上都成立。哪家好用会变，这些概念不会。

**不讲原理。** 注意力机制、Transformer、参数量怎么算——这些跟你把活干好没关系，一律不展开。真想深挖，[术语表](../reference/glossary)里给了词，你自己去搜。

**例子都能直接抄。** 提示词全部写成可复制的整段，不是"你可以这样写"的示意。

::: tip 已经天天在用 AI 了，还需要读吗
需要。检验一下：你能不能一句话说清"它为什么会编"和"它为什么会忘"？如果说不清，你现在的用法大概率是靠手感——手感在简单任务上够用，一到重要的活就露馅。
:::

## 从哪儿开始

第一次接触，从 [01 · 大模型是什么](./01-what-is-llm) 开始顺着读。

已经用了一阵，想补概念，直接跳 [03 · Token](./03-token) 和 [04 · 上下文窗口](./04-context)——这两个是最多人没搞明白、又最影响结果的。

只想马上做出个东西来，直接去 [08 · 上手做第一件事](./08-first-task)，回头再补前面。

# 06 · Prompt 五要素：把话说到它不用猜

<div class="ab-def">

**Prompt**（提示词）就是你每次**交代给 AI 的那段话**。同一个模型，话说得清不清楚，结果天差地别。研究怎么把这段话说好，有个专门的名字叫「Prompt Engineering」——但你不需要那个名头，你需要下面这五格。

</div>

## 五要素不是规矩，是被两个毛病逼出来的

先别急着背。看这个推导：

| 它的毛病 | 于是你必须 | 这就是 |
| --- | --- | --- |
| [会忘](./04-context)——桌面摊不下，不记得上次 | 一次把该知道的背景给全 | **背景** |
| [会忘](./04-context)——你不说它就自由发挥 | 明确要什么结果、什么格式 | **要求** |
| [会编](./05-hallucination)——不懂装懂 | 提前把"不许编"写成条款 | **验收** |
| 不认识你——不知道该站在什么立场 | 告诉它扮演谁 | **角色** |
| 它只会接着你的话往下写 | 说清到底要它干什么 | **任务** |

**五要素：角色 / 任务 / 背景 / 要求 / 验收。** 现在它们不是"要背的五条"，是"想想就懂的五条"。

## 一格一格看

### 角色 —— 让它知道自己扮谁

```text
你是一位专业的项目助理。
```

作用是把它的语气、术语、关注点一次性调对。写"你是一位资深产品经理"和"你是一位法务"，同一份材料它盯的地方完全不同。

一句话就够，别写成简历。

### 任务 —— 到底要它干什么

```text
请把下面这段零散的会议记录，整理成一份结构清晰的会议纪要。
```

一次一个动词。"整理成纪要**并且**分析风险**并且**起草邮件"——三件事混在一起，三件都做不好。

### 背景 —— 一次把该知道的给全

```text
背景：这是我方与客户「明远地产」就"会员小程序改版"项目的一次沟通会，
参会方包括我方、客户市场部（刘总监）和客户技术人员。
```

这一格是最多人跳过、也最影响结果的。它不认识你的客户、不知道你们的行话、不知道这份东西给谁看。**你觉得"这还用说吗"的东西，正是它不知道的东西。**

### 要求 —— 要什么结果、什么格式（★ 最关键）

```text
请按以下三块输出：
一、关键结论 / 已定事项
二、待办事项（每条标出：事项、负责人、截止时间）
三、遗留 / 待确认问题

条目化、简洁，待办要能直接拿去派活。
```

含糊的要求 = 含糊的结果。"整理清楚一点"——什么叫清楚？分几块？要不要把"谁该干什么"单拎出来？**你不说，它就替你决定。**

### 验收 —— 不许编，拿不准就标出来

```text
只能基于我给的内容整理，不要编造没提到的信息；
负责人或时间不明确的，标注「待确认」，不要自行猜填。
```

见 [05 · 幻觉](./05-hallucination)。这一格是很多人从来没写过的，也是最能把"看着像样"变成"真能用"的一格。

## 差别有多大

**含糊地说：**

```text
帮我把会议记录整理一下。
```

拿到的是一段重新排版的流水账——它把你说的话换了个说法复述一遍，该提取的待办还埋在里面。

**说清楚：**

角色 + 任务 + 背景 + 要求 + 验收 五格齐全。

拿到的是一份带责任人和截止时间的待办清单，以及一份明确标出"待确认"的遗留问题列表——**可以直接发到群里派活。**

完整的对照演示在 [08 · 上手做第一件事](./08-first-task)。

## 几种常见写法

这四个词你会在各种教程里反复看到，一句话说清：

| 写法 | 意思 | 什么时候用 |
| --- | --- | --- |
| **Zero-shot** | 不给例子，直接说要求 | 大多数情况，先试这个 |
| **Few-shot** | 附几个"输入→输出"的示例 | 格式很挑、说不清但能举例的时候 |
| **思维链**（CoT） | 让它"一步步想"再给结论 | 需要推理、算数、多条件判断时 |
| **角色扮演** | 就是五要素里的"角色" | 需要特定视角或语气时 |

Few-shot 是被低估的一招：**当你发现自己怎么描述都说不清想要什么格式，就别描述了，给两个例子。**

::: tip 关于「思维链」
现在的推理型模型（会先"想"一段再答的那类）已经内建了这个过程，你再手动写"请一步步思考"意义不大。但在普通模型上，这一句仍然有效。
:::

## 三个最常见的错误

**一、太客气。** "能不能麻烦你帮我看看这个大概怎么处理比较好呢"——礼貌不加分，含糊要扣分。直接说要什么。

**二、一次问太多。** 一段话里塞了五个诉求，它会挑好写的答，剩下的敷衍过去。拆开，一次一件。

**三、"你懂我意思吧"。** 它不懂。**它连你在哪个行业都不知道。**

## 一个可以直接抄走的模板

```text
你是【角色】。

请【任务，一个明确的动词】。

背景：
【它必须知道但绝不可能自己知道的事：项目、客户、给谁看、有什么忌讳】

要求：
1. 【输出结构：分哪几块】
2. 【格式：表格 / 条目 / 段落，详略程度】
3. 【语气：正式 / 口语 / 对外 / 对内】

验收：
- 只能基于我给的内容，不要编造没提到的信息；
- 拿不准的地方标注「待确认」，不要自行猜填。

材料如下：
【粘贴你的原始材料】
```

更多现成模板在[提示词模板库](../reference/prompts)。

# 01 · 大模型是什么

<div class="ab-def">

**大模型**（LLM，Large Language Model）是一个读过海量资料的引擎，本事只有一个：**根据你给的输入，预测下一个字最可能是什么**。写方案、改代码、整理纪要，全都是这一件事反复做出来的。

</div>

## 它干活的样子

你给它一段话，它一个字一个字地往下接，接到该停的时候停下：

```text
你的输入：帮我把这段会议记录整理成纪要
        ↓
大模型：预测下一个字 → 预测下一个字 → 预测下一个字 …
        ↓
输出：一份结构化的会议纪要
```

关键在于中间那一步**不是查询**。它没有一个"会议纪要模板库"去检索，也没打开你的硬盘。它是在几千亿个参数里算：见过那么多文本之后，跟在这段话后面最合理的下一个字是什么。算完一个，把它接上，再算下一个。

这听起来太简单了，简单到不像能写出一份能用的方案。但事实是：当"预测下一个字"这件事做得足够准、见过的文本足够多，写作、翻译、推理、写代码这些能力就一并出来了。为什么会这样，学界到现在也没完全讲清楚。你不需要理解它，你需要记住它——**因为它带来的所有好处和所有毛病，都从这一句话来**。

## 三个必须知道的特点

| 特点 | 意思 | 后果 |
| --- | --- | --- |
| **很能干** | 读过海量公开资料，能读能写，各行各业都懂一点 | 你可以直接派活，不用教它中文和常识 |
| **不认识你** | 不知道你公司的文档、客户、内部规矩、上周开的会 | 该给的背景每次都得自己给 |
| **自己啥也做不了** | 光靠模型本身不能联网、不能读你的文件、不能动手——只会"说" | 想让它干实事，得额外给它接工具（后面 [09 · 全景地图](./09-map) 讲） |

第三条最容易搞混，因为你在 ChatGPT 里明明看见它联网搜过。那是**产品**帮它接上了搜索工具，不是**模型**本身会上网。模型是引擎，产品是整辆车。分清楚这一层，后面 Agent、MCP 那些词才不会糊成一团。

## 它不是什么

**不是搜索引擎。** 搜索引擎返回的是真实存在的网页，它返回的是算出来的一段话。两者可能都对，来源完全不同。

**不是数据库。** 你训练时喂进去的东西不是原样存着的，是被揉进参数里的。所以它复述细节的时候可能走样——这是原理决定的，不是 bug。

**不是有记忆的助理。** 每一次对话它都是从头读一遍上下文。所谓"它记得我"，是产品把历史又发了一遍给它。见 [04 · 上下文窗口](./04-context)。

**不是稳定的。** 同一个问题问两遍，答案可能不一样。它在候选字里带着随机性挑，不是每次都选概率最高那个（这个随机程度就是「Temperature」）。

::: warning 于是有了那个著名的副作用
既然是"预测"不是"查证"，那当它不知道的时候，它也不会停——它会继续预测出一段**读起来非常合理、但完全是编的**内容。这叫**幻觉**，是 [05](./05-hallucination) 的主题，也是这本书里唯一一个我会反复提醒你的东西。
:::

## 常见的大模型有哪些

| 阵营 | 常见的几家 |
| --- | --- |
| 国外 | GPT（OpenAI）· Claude（Anthropic）· Gemini（Google）· Llama（Meta，开源） |
| 国内 | DeepSeek · 豆包（字节）· 通义千问（阿里）· Kimi（月之暗面）· 文心（百度）· 智谱 |

具体哪家现在最强，这个月和下个月的答案可能就不一样，本书不排名。真正影响你结果的是**你怎么交代任务**，而不是你选了哪一家——这句话在你亲手做完 [08 · 第一个任务](./08-first-task) 之后会更有体感。

每家分别是谁、以什么见长，以及文本 / 多模态 / 语音这些类别各自解决什么问题，见[模型篇](../models/)。选型的判断维度在 [10 · 选模型、选工具](./10-choose-and-rules)。

## 记住这一句就够

> 它是一台预测下一个字的机器。很能干，但不认识你，也没法自己动手。

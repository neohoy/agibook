# Workflow 篇 · 把几步串成一条流水线

你现在能把**一步**做好了：[一条提示词说清楚](../prompt/)，[打包成一个 Skill 反复用](../skill/)。

但真实的活很少只有一步。

> 会开完了 → 整理成纪要 → 从纪要里拆出待办 → 按责任人分组 → 生成各自的派活消息 → 你过一遍 → 发出去。

六步。你现在的做法大概是：开个对话，把第一步跑完，复制结果，再开一轮，再复制……跑到第四步发现第二步漏了个人，回头重来。

**这一篇讲的就是怎么把这几步串成一条能重复跑、每步都能验收、出错知道停在哪的流水线。**

## 一句话，先给你

这一篇最想让你记住的是这句：

> **大多数人以为自己需要一个 Agent，其实需要的是一条 Workflow。**

区别在于**谁来决定走几步**：

- **Workflow**：你把步骤定死，它照着走。慢一点、笨一点，但**每次都一样**，错了知道错在第几步。
- **Agent**：你给一个目标，它自己决定走几步。灵活，但**每次不一样**，错了你得从头翻。

一件你已经知道该怎么做的事，让它自己"想"一遍怎么做，不是聪明，是浪费——**还把一件可控的事变成了不可控的事**。

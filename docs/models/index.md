# 模型篇 · 模型地图

[入门篇](../start/)说过：**它是一台预测下一个字的机器**。这一篇回答的是下一个问题——**市面上有哪些台**。

::: warning 先说清楚：这是全书最容易过期的一篇
本书其余部分刻意[不写会过期的东西](../reference/credits)。这一篇是唯一的例外，因为"有哪些模型"这个问题绕不过去。

所以它用一种能扛住时间的写法：

- **不写版本号**——写了下个月就是错的；
- **不写跑分和排名**——榜单和你的任务多半没关系；
- **不写价格**——变得比版本还快；
- **只写**：这家是谁、家族叫什么、**结构上以什么见长**、官方入口在哪。

最后一条是关键：**每家都给了官网链接，具体情况你自己去看一眼。** 这一篇的作用是让你知道该看谁，不是替你看。

内容截至 **2026 年 9 月**。看到和官网不一致的地方，以官网为准。
:::

## 三条先给你的判断

### 一、选哪家的影响，小于你怎么交代任务

[入门篇 10 章](../start/10-choose-and-rules)那句话在这里再说一遍，因为最多人卡在这儿：

> **同一个模型，话说清楚和说不清楚的差距，比换一家模型大得多。**

你在[入门篇 08 章](../start/08-first-task)已经亲手验证过这一点。所以别把选型当成第一优先级——**它是一个二十分钟就该有答案的问题**，方法在 [04 章](./04-how-to-choose)。

### 二、"以什么见长"是印象，不是能力上限

后面两章里每家都有一句"以什么见长"。那说的是**这家的历史路径和产品重心**，不是"别的它做不了"。

各家都在往全能方向补齐。**看到"某家以长文本见长"，不要理解成"别家处理不了长文本"。**

### 三、真正稳定的差别，不在能力，在能不能用

能力排名每个月都在变，但这几条几乎不变，而且它们才是真正决定你用哪家的：

| 维度 | 为什么它比跑分重要 |
| --- | --- |
| **数据能不能出境 / 出内网** | 这是硬约束。多数公司先卡这一条，再谈好不好用 |
| **有没有开放权重** | 决定你能不能私有化部署、能不能二次训练 |
| **生态和集成** | 你用的那些工具支不支持它 |
| **可及性** | 账号、付款、网络——能不能稳定地用上 |

这四条在 [04 章](./04-how-to-choose)展开。

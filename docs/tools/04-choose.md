# 04 · 怎么挑、怎么换

<div class="ab-def">

跟[模型篇 04 章](../models/04-how-to-choose)一样的顺序：**先按硬约束筛，再花一个下午实测**。但工具比模型多一条要考虑——**换工具的成本比换模型高**，因为你的规则文件、Skill、习惯都长在上面。

</div>

## 三道硬约束

### 一、公司允不允许

桌面工具能读你的文件、能连外网。这两条决定了它必须先过合规：

```text
问清楚三件事：
1. 允不允许在办公电脑上装这类工具？
2. 代码 / 文档能不能被它读走、发到外部？
3. 有没有必须用内部平台的规定？
```

**这一条通常不由你决定，但也通常最先卡死。** 先问，再试。

### 二、你的活在哪儿

| 你的活主要在 | 该看哪一档 |
| --- | --- |
| 聊天框里就能做完（写、改、整理） | [便签纸](./01-workstation)，不用换 |
| 本地的一堆文件（文档、素材、表格） | 办公 Agent（豆包、WorkBuddy 那类） |
| 代码库 | 编码工具（Claude Code、Codex、Trae、Qoder、OpenCode 那类） |
| 某个垂直产出（视频、音乐、设计） | [专用工具](./03-specialized) |

**别按"哪个更强"挑，按"我的活落在哪儿"挑。** 不写代码的人装一个 IDE，多出来的全是负担。

### 三、能不能稳定用上

账号、付款、网络、发票、团队授权。**十个人用，三个人登不上，这个选型就是失败的。**

## 然后：一个下午实测

<div class="ab-do">

**挑两个候选 → 各用半天 → 干你本周真实的活。**

别用它的示例项目，用你手上真的东西。半天之后问自己四个问题：

1. **它认得我的项目吗？** 还是每次都要重新交代背景。
2. **规矩能不能写下来？** 有没有规则文件 / Skill 这类机制，让约定自动生效。
3. **出错的时候我看得见吗？** 它改了哪些文件、跑了什么命令，能不能查、能不能撤。
4. **卡住的时候我知道为什么吗？** 还是只能重开一次碰运气。

第 3、4 条最容易被忽略，但它们决定了三个月后你是在用它，还是在骂它——**跟 [Workflow 篇 09 章](../workflow/09-tools)选编排工具那四条是同一个道理**。

</div>

## 安全底线：桌面工具版

这一节不能省。桌面工具能动你的真东西，[Agent 篇 05 章](../agent/05-boundaries)那套边界在这里全部适用：

**一、别在有重要东西的目录里第一次试。** 新建一个测试目录，把它圈在里面。

**二、用版本控制。** 有 Git 的项目里，它改坏了你能一键回滚——这是最便宜的保险。没有版本控制就让 AI 改文件，是在裸奔。

**三、危险动作保持确认。** 多数工具有权限档位（只读 / 需确认 / 完全放开）。**"完全放开"省下的那几次点击，不值得你冒那个险**，至少在你摸清它的脾气之前。

**四、装扩展和 MCP Server 之前先看一眼。** [Agent 篇 04 章](../agent/04-mcp)那五条检查在这里同样适用——来源、权限、提供哪些工具、会不会往外发数据、凭据怎么存的。

**五、凭据别硬编码。** 明文写在配置文件里的 key，你机器上任何程序都能读，AI 也能读。

## 换工具的成本，比你以为的高

::: warning 别因为看了篇文章就换
换模型是改个配置。换工具要重来的东西多得多：

- 规则文件的写法（各家不一样）
- Skill / 技能的组织方式
- MCP 或扩展的配置
- 你自己的肌肉记忆
- **团队里其他人的学习成本**——这一条最贵

所以：**遇到具体的墙才换，不是看到更好的就换。**
:::

什么算"具体的墙"：

- 它读不到你必须让它读的东西；
- 它连不上你必须连的系统；
- 合规上不让用了；
- 团队定了别的。

"听说 X 更强"不算墙。

## 最重要的一条

<div class="ab-do">

**工具决定你能干什么，方法决定你干得好不好。**

这本书前五篇讲的全是方法——[五要素](../prompt/)、[Skill 怎么写](../skill/)、[流水线怎么串](../workflow/)、[Agent 的边界怎么划](../agent/)。**这些换到哪个工具上都成立**，因为它们针对的是模型的性质（[会忘、会编](../start/)），不是某个产品的功能。

所以真正的分配应该是：**选工具花一个下午，练方法花三个月。**

反过来做的人很多——每周试一个新工具，每个都只到"跑通 hello world"，然后觉得 AI 也就那样。

</div>
